# Cognpulse — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Cognitive programme lead

- As programme lead, I want initiatives tagged by technology and objective, so that I can see we are over-indexed on internal RPA.
- As programme lead, I want segment scores per unit, so that I apply Wader vs Fast Lane playbooks deliberately.

### CIO

- As CIO, I want integration risk visible before funding, so that cognitive projects do not die on legacy interfaces.
- As CIO, I want vendor fragmentation mapped, so that we consolidate without romanticising in-house builds.

### HR / workforce lead

- As HR, I want jobs-added vs jobs-lost expectations by initiative, so that our narrative matches the survey’s mostly positive pattern without denial of future moderate loss.
- As HR, I want talent gaps on deep learning/NLP flagged, so that hiring matches sophistication ambitions.

### Initiative owner

- As an owner, I want benefit re-attestation reminders, so that early bullishness gets refreshed with evidence.
- As an owner, I want clear portfolio lane (capability vs transformational), so that I know which success bar applies.

### Vendor manager

- As vendor manager, I want dependency patterns by segment, so that Wader teams get enablement, not only more licenses.
- As vendor manager, I want multi-vendor overlaps visible, so that we reduce fragmentation.
